# Roadmap

The goal is useful companions and a believable ArcheAge world population. AAEmu 1.2 is the active target. The 3.0 adapter is frozen for compatibility maintenance.

## Available foundation

Persistent characters, party orders, role-based combat, configurable rotations, and diagnostics are present. Fresh-character creation, supported native quest lifecycles, and road-assisted movement are experimental. These pieces are not yet an accepted autonomous living world.

## Current focus: one fresh Nuian

One newly created level-one Nuian should find, accept, travel to, complete, report, and chain five eligible starter quests without per-action operator commands. It should prioritize main story while considering nearby side quests, use native progress, and explain unsupported or blocked work.

Acceptance requires visible movement and interaction in an active client, matching server outcomes, and persistence across a graceful restart of the same candidate. Earlier gameplay observations are supporting evidence; the final candidate's repeat and restart gate remain pending.

## After that works reliably

| Step | Player-visible result |
| --- | --- |
| Small starter population | Three persistent bots choose and complete nearby activities without following one scripted route |
| Goal-driven travel | Bots reach legitimate distant objectives through roads and local movement, with bounded recovery |
| One-zone population | Questing, combat, gathering, rest, and social activity remain useful during a sustained run |
| Functional scale | Increase populations only while accepted activities, server responsiveness, and recovery remain sound |
| Group content | Cooperative roles, dungeons, and native PvP |
| ArcheAge world life | Labor, professions, trade, transport, housing, guilds, and territorial activity |

No dates or capacity numbers are promised. A larger idle-bot count does not prove functional population scale. Richer population and travel features follow the starter gameplay foundation.
